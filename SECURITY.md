# Security Policy

## Supported version

Security fixes are applied to the latest code on the `main` branch. This project is a frontend starter, so adopters remain responsible for reviewing their own deployment, content, integrations, and dependency updates.

## Report a vulnerability

Please use [GitHub private vulnerability reporting](https://github.com/LvvUP/shadcn-landing-page/security/advisories/new). Do not disclose a vulnerability in a public issue or discussion.

Include a concise description, affected files or versions, reproduction steps, impact, and any suggested mitigation. Remove credentials, personal information, and unrelated private data from your report.

You should receive an acknowledgement within seven days. Timelines for validation and remediation depend on severity and maintainability. Please allow a reasonable remediation window before public disclosure.

## 安全问题报告

请通过 [GitHub 私密漏洞报告](https://github.com/LvvUP/shadcn-landing-page/security/advisories/new) 提交安全问题，不要在公开 Issue 或 Discussion 中披露漏洞。报告中请提供影响范围、复现步骤和必要的脱敏信息，切勿包含密钥、个人信息或无关的私有数据。
